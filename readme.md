# 🧪 Caso Prático – Projeto JavaScript

Este projeto foi desenvolvido como parte de um caso prático do curso de desenvolvimento web com foco em **JavaScript**, **HTML** e **CSS**. Inclui a criação de um site multi-página com funcionalidades dinâmicas e interativas, sem o uso de CMS ou frameworks pesados.

---

## 🚀 Funcionalidades principais

-   🌐 Estrutura multi-página com navegação entre:

    -   `index.html` – Página principal
    -   `contactos.html` – Página de contacto com formulário validado
    -   `orcamento.html` – Calculadora dinâmica de orçamentos
    -   `portfolio.html` – Exibição de projetos simulados

-   🧠 Uso de **JavaScript puro** para:

    -   Validação de formulários
    -   Atualização de conteúdos em tempo real
    -   Manipulação do DOM

-   🖱️ Interatividade com **jQuery** (se aplicável)

-   🧭 Mapa interativo com **Leaflet** (caso incluído)

-   📰 Leitor de **RSS dinâmico** com AJAX e JSON (caso incluído)

---

## 🧱 Tecnologias utilizadas

-   HTML5
-   CSS3
-   JavaScript
-   (Opcional) jQuery
-   (Opcional) Bootstrap
-   (Opcional) Leaflet
-   (Opcional) All-in-One WP Migration (para projetos anteriores)
